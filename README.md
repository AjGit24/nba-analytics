# NBA 2023-24 Performance Analysis

A data analytics project exploring NBA player performance during the 2023-24 season using Python, SQL, and Tableau.

## Dashboard
[View on Tableau Public](https://public.tableau.com/views/NBA2023-24PerformanceAnalysis/Dashboard1)

## Key Insights
- Joel Embiid led the league in scoring at 34.7 PPG
- Khris Middleton showed the biggest playoff improvement, scoring 9.6 more points per game than the regular season
- Dereck Lively II was the most efficient scorer with a 74.7% eFG

## Tools Used
- Python (pandas, sqlalchemy)
- SQLite
- Jupyter Notebook
- Tableau Public

## Project Structure
- `data/` — Raw and processed CSV files, SQLite database
- `notebooks/` — Jupyter notebooks for data exploration
- `sql/` — SQL queries used for analysis
